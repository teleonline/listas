# Lista IPTV Teleonline

Repositorio con actualización automatica de canales de television (IPTV) y Guia Electronica de Programacion (EPG).

Este proyecto genera listas de reproduccion limpias, optimizadas y actualizadas diariamente para asegurar la maxima compatibilidad con reproductores como TiviMate, IPTV Smarters, VLC y OTT Navigator.

### Aviso Legal

Este repositorio no aloja ni transmite ninguna señal de video. Los enlaces que hay en este repositorio son unicamente listas de acceso oficial que apuntan a servidores de terceros o emisiones publicas disponibles en Internet. 
No nos hacemos responsables de la disponibilidad, contenido o legalidad de las transmisiones enlazadas.
